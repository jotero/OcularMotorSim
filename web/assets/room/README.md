# web/assets/room

Furnished room used as the 3D view's visual surround (`web/room.js`), the
alternative to the dot cloud. All assets are from [Poly Haven](https://polyhaven.com)
and are **CC0** (public domain), 1k resolution.

Models were reduced to base-colour textures only (normal / ARM / AO / roughness maps
dropped, materials set non-metallic, clock-glass transmission replaced by plain
alpha) to keep the download small.
